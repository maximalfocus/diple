# S-016 — Blocks as fine as the screen draws them

The acceptance cases for issue #50. Unit cases use injected clocks and
in-memory terminals; host cases use tiers 4 and 5, in both drawing modes.

| Case | Level | Exercise | Passes when |
|---|---|---|---|
| T-01 | unit | A missing or corrupt transcript over a tight, nested list | Each list item, nested ones included, is its own block |
| T-02 | unit | Fallback over a lead-in, list items, fences, turn markers and shallower indents | Each starts a separate fallback block |
| T-03 | unit | Each adapter given a transcript from an unverified runtime version | It parses and aligns it; `diple blocks` labels it unverified; a fixture at that version is refused, naming the version |
| T-04 | unit | One unmatched block (a list from `3.`, a link, a wrapped table) | It falls back without losing the matches before and after it |
| T-05 | unit | The committed adapter fixtures | They align unchanged |
| H-01 | host, driven | An installed Claude Code, in `tmux` and one windowed host | One list item raises alone |
