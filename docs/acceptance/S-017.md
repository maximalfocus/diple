# S-017 — Copy what the selection shows

The acceptance cases for issue #52. Unit cases use injected clocks and
in-memory terminals; the host case uses tiers 4 and 5, in both drawing modes.

| Case | Level | Exercise | Passes when |
|---|---|---|---|
| T-01 | unit | A list item with emphasis, inline code and a link | Its visible characters are copied, marker included |
| T-02 | unit | Drags starting before and after a visible list marker, and across a turn marker | Each copies its own highlight; the turn marker is neither highlighted nor copied |
| T-03 | unit | CJK, combining accents and a ZWJ emoji before and inside a selection | Each copies once, in place |
| T-04 | unit | Soft wraps, agent wraps, literal spaces, renderer indent, hard breaks, unaligned output | Soft and agent wraps join; literal spaces survive; renderer-added indent drops; hard breaks remain; unaligned output copies screen rows |
| T-05 | unit | Double-press, triple-press, the strip's `copy`, and `c` | Each copies what it highlights |
| T-06 | unit | Output and a change of tray height after a selection is made | The selection's text is the text first selected |
| H-01 | host, driven | All four claimed hosts at their recorded versions, both drawing modes | All five copy actions and T-01 to T-06's text cases pass live; the harness reads each copy back from the clipboard before the next action and compares it with the expected visible text |
